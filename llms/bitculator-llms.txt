# Bitculator

> Bitculator is a cryptocurrency market-data, analytics, and developer-API platform. It tracks thousands of coins and tokens across major exchanges — real-time prices, market capitalisation, 24-hour volume, circulating and max supply, all-time highs and lows, exchange trust scores, and hardware/software wallet reviews — plus proprietary market-sentiment analytics: a crypto Fear & Greed index, a Bull/Bear index, an Altseason index, and a market-wide technical-indicator tally. The same data is available on the website (in 19 languages) and through a Bearer-authenticated REST/JSON API.

Developers use the **Bitculator Data API**, a REST API with base URL `https://bitculator.com/api/v1`. Every request authenticates with an `Authorization: Bearer <API_KEY>` header (create a free key in the developer console). Responses use a `{ data, meta }` JSON envelope, and prices, rates and supplies are returned as exact decimal strings (never lossy floats). Endpoints are grouped into: coins & prices, markets & tickers, exchanges & trust scores, wallets, technical indicators, sentiment indices, global market aggregates, currency conversion, editorial content, and webhooks/alarms. There are three plans — **Free, Starter, Pro** — each with a monthly request quota and per-minute burst limits.

## Localisation

**Every page URL below applies to all 19 languages.** The links are shown in their canonical English form (`/en/…`); swap the `/en/` path segment for any supported locale code to get the exact same page, translated:

`en`, `de`, `fr`, `es`, `it`, `nl`, `da`, `no`, `sv`, `ru`, `ja`, `zh`, `tr`, `pt`, `vi`, `id`, `pl`, `uk`, `cs`

Example: `https://bitculator.com/en/crypto-markets` → `https://bitculator.com/de/crypto-markets`. The machine artifacts (`/api/v1/openapi.json`, the Postman collection, and the API itself under `/api/v1`) are locale-agnostic and carry no `/en/` segment.

## Data API
- [API documentation](https://bitculator.com/en/documentation/api/v1): Complete reference for the Bitculator crypto Data API — every endpoint, query parameter, authentication, rate limits and quotas, the error envelope, and copy-paste code examples in cURL, JavaScript, PHP and Python.

- [Postman collection](https://bitculator.com/documentation/api/v1.postman): Ready-to-import Postman collection for the Data API.

- [Developer console](https://bitculator.com/en/user/developer/api): Create and manage Bearer API keys (the `data-api` ability) and view usage and quota — requires a free account.
- [Embed widgets documentation](https://bitculator.com/en/documentation/embed/v1): Free embeddable crypto widgets (iframe) for any website — currency converter, price-history chart, and DCA / profit / interest / loan / staking / tax calculators.
